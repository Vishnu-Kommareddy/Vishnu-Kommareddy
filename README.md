## 🔬 Research Focus

My PhD research centers on **Network Slice Orchestration and Security in Cloud Infrastructures**, addressing:

- **Security Isolation in Multi-Tenant Network Slices**: Developing mechanisms to ensure strong isolation between co-existing network slices in shared cloud/NFV infrastructure.
- **Policy-Driven Security Orchestration**: Automating security policy enforcement across slice lifecycles using intent-based policies and zero-trust principles.
- **Threat Detection for Sliced Networks**: Leveraging ML-driven anomaly detection and real-time monitoring to identify threats in virtualized 5G/6G network functions.
- **Secure Resource Allocation**: Optimizing slice resource allocation while maintaining security constraints and SLA guarantees.
- **Cloud-Native Security for 5G/6G**: Applying container security, service mesh, and eBPF-based observability to protect network function deployments.
